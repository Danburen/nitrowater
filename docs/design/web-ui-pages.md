# NitroWater 业务端 Web —— 页面 / 功能 / 按钮清单与 UI 调整建议

> 用途：把 `nitrowater-web`（业务门户，非 SSO 的 `admin-ui/auth-ui`）当前每个页面的结构、功能、按钮
> 逐页摊开，作为 UI 设计师改版、评审、出图的输入。
>
> 代码位置：`nitrowater-web/src`。本文以当前代码为准（2026-11），按钮文案即界面文案。
> 本轮已经落地的调整见第 7 节；待设计决策见第 8 节。

---

## 1. 项目速览（和 UI 相关的部分）

| 模块 | 作用 | 与前端的关系 |
| --- | --- | --- |
| `nitrowater-web` | Vue 3 门户（本文对象） | 唯一面向最终用户的 Web 界面 |
| `nitrowater-bff` `:8080` | BFF，负责登录态与 `/api/**` 代理 | 前端所有请求走 `/api/**` |
| `nitrowater-server` `:8081` | 业务服务：插件、AI、文档检索 | 插件中心、NitroBot、管理后台数据 |
| `nitrowater-resource` `:8093` | 资源/文件服务 | 插件下载、资源管理 |
| `nitrowater-account` `:8090` | SSO/OIDC + 独立 `admin-ui` / `auth-ui` | 不在本文范围 |

前端栈：Vue 3 + TypeScript + Vite + Tailwind CSS v4 + Element Plus（表格/表单/抽屉等）
+ vue-router。图表用 ECharts，代码编辑器用 CodeMirror，Markdown 用 marked + DOMPurify。

### 1.2 四个「壳」（同一产品，四种导航形态）

| 壳 | 路由 | 结构 | 现状问题 |
| --- | --- | --- | --- |
| 门户顶栏 | `/` `/about` `/account` | 60px 顶栏 + 最大 1120px 内容列 | 与其它壳的顶栏高度/内边距不同 |
| 分区侧栏 | `/tools/**` `/plugins/**` | 左侧 210px 侧栏（可折叠）+ 右侧内容 | 和插件中心的搜索框、工具箱的分组标题是同一套组件 |
| 聊天全屏 | `/chat` | 264px 会话侧栏 + 52px 顶栏 + 760px 消息列 + 底部输入 | 会话侧栏可整体收起；移动端抽屉 |
| 管理后台 | `/admin/**` | 220px 侧栏 + 52px 顶栏 + 最大 1120px 内容 | 侧栏菜单、账号菜单与门户一致，但按钮体系偏 EP |

> 设计统一时优先处理：三种侧栏宽度（210 / 220 / 264）、两种顶栏高度（60 / 52）、
> 折叠按钮的不同图形语言。

## 3. 全局导航与共享控件

### 3.1 门户顶栏（`shared/ui/AppHeader.vue`）

| 元素 | 行为 |
| --- | --- |
| Logo + NitroWater | 回 `/` |
| 工具箱 / 插件中心 / NitroBot / 关于 | 路由跳转；`<md` 隐藏，仅保留右侧操作 |
| 运维（仅 ADMIN） | 跳 `/admin/resources` |
| 主题切换 | 暗/亮切换，写 `localStorage` |
| 登录（未登录） | 走 BFF OIDC 登录，回跳当前页 |
| 退出未完成，重试 | 上次登出未完成时出现（红色描边小按钮） |

### 3.2 账号菜单（`shared/ui/UserMenu.vue`，门户 + 后台共用）

触发：头像（无头像时首字母）+ 昵称 + `▼`。菜单项：

1. 账号列表：点击切换账号（当前账号禁用，右侧「当前」）
2. 用户中心 → `/account`
3. 添加账号（多账号会话）
4. 退出当前账号（确认框）
5. 退出全部（红色）

### 3.3 分区侧栏（`shared/ui/SectionLayout.vue`）

- 桌面：返回门户箭头 + Logo + 分区名 + 折叠按钮；导航（总览 + 分组）；底部主题 + 登录/退出。
- 移动：48px 顶栏 = 返回 + 原生 `<select>` 导航 + 主题。
- 折叠状态写 `localStorage`（`nitrowater:{tools|plugins}-sidebar-collapsed`）。
- 插件中心额外在导航上方放「搜索插件…」输入框。

### 3.4 页面标题（`PageShell.vue` / `AdminPage.vue`）

- 工具页：`标题 + ⓘ（说明浮层）+ 右侧操作槽`，下方内容区独立滚动。
- 管理页：`H1 + 一句描述 + 右侧操作槽`，内容区内边距统一，块间距 16px。

### 3.5 弹层与提示

- 自定义 Tailwind 弹层：`AppDialog`（确认/表单）、`AppDrawer`（侧滑）、`ConfirmHost`（危险确认）、`ToastHost`（右下轻提示）、`UiTooltip`。
- Element Plus 弹层：`el-drawer`（技能、工具详情）、`el-popconfirm`（MP4 转 GIF 更换视频）、`ElMessageBox`（后台配置页）。
- **现状不统一**：同样是「删除确认」，插件/资源/用量/技能走 `confirm()`，账号菜单用原生 `window.confirm`，登录退出也有原生确认。

## 4. 逐页清单

> 说明：`位置` 指按钮出现在页面的哪一层；`状态` 记录禁用/加载/条件显示。

### 4.1 `/` 门户首页

结构：Hero（徽章 + 主标题 + 说明 + 两个 CTA）→ 在线工具箱（分组卡片）→ 插件中心（卡片）→ 页脚。

| 位置 | 按钮 / 元素 | 行为 |
| --- | --- | --- |
| Hero | 进入工具箱 | 跳 `/tools`（主按钮） |
| Hero | 浏览插件中心 | 跳 `/plugins`（次按钮） |
| 工具箱分区右上 | 查看全部 → | 跳 `/tools` |
| 工具箱 | 每个工具卡片 | 跳对应 `/tools/*`；无「soon」卡片 |
| 插件分区右上 | 进入插件中心 → | 跳 `/plugins` |
| 插件分区 | 每个插件卡片 | 跳 `/plugins/:key`；空数据时显示「暂无插件。」 |
| 页脚 | 关于 / GitHub / Gitee | 站内 / 外链 |

状态：插件列表请求失败时静默降级为空列表（无错误提示）。

### 4.2 `/tools` 工具箱总览

| 位置 | 按钮 / 元素 | 行为 |
| --- | --- | --- |
| 侧栏 | 工具箱总览 + 分组导航 + 折叠 + 主题 + 登录/退出 | 见 3.3 |
| 内容 | 两组工具卡片（我的世界服务 / 通用功能） | 跳工具页；`soon` 卡片降透明度 + `soon` 徽标（当前无 soon 工具） |
| 底部 | 开源鸣谢 → | 跳 `/about#credits` |

### 4.3 工具页通用骨架

所有工具页 = `PageShell`（标题 + ⓘ 说明 + 右上操作）+ 若干 `panel` 卡片。
按钮体系以 Tailwind `.btn` / `.btn-primary` / `.btn-sm` / `.icon-btn` 为主，
少数页面混用 `el-button`（下表标注）。

#### `/tools/motd` MOTD 格式化预览

- 左：输入面板（恢复示例；颜色块；格式按钮 B/I/U/S/混淆；换行；十六进制取色 + 插入颜色；复制纯文本 / 复制 legacy；`&` 与警告提示）。
- 右：服务器列表预览（两行近似渲染、标签「近似效果」）。
- 下：输出面板（选项卡 legacy / server.properties / JSON；「转义非 ASCII」复选；复制；下载文件）。

#### `/tools/server-properties` server.properties 生成 / 校验

- 顶部工具条：预设组、选择文件、粘贴导入（展开/收起）、恢复默认。
- 导入面板：清空、导入配置。
- 左侧分组导航（带错误数徽标）；右侧字段表单（分组标题 + 字段数 + 错误数）。
- 底部输出：校验状态、转义非 ASCII、复制、下载 server.properties（有错误时禁用）。
- 提示：导入 warnings、未知键预览、Java 版说明。

#### `/tools/server-icon` server-icon 生成

- 左：64×64 预览画布（拖动/滚轮/双击居中）、选择图片/更换图片、居中、重置缩放。
- 右：文件名与原图信息、缩放滑杆、背景选择（透明/纯色）、下载 server-icon.png。
- 说明：非正方形裁切提示、放置位置提示。

#### `/tools/start-script` 启动脚本生成

- 顶部：平台切换（Windows / Linux 分段控件）、预设、恢复默认。
- 左：服务端 JAR、Java 路径、内存、Aikar flags、自动重启、额外参数等字段（带校验与提示）。
- 右：生成的脚本（行尾/行数）、复制、下载 start.bat / start.sh（有错误时禁用）、warnings、代码预览。

#### `/tools/java-to-ts` Java DTO 转 TypeScript

- 左：Java 输入（复制/清空图标按钮）、文本域、生成默认值 / 生成校验规则、转换为 TypeScript（主按钮）。
- 右：TypeScript 输出、复制。

#### `/tools/zip` 压缩 / 解压

- 分段选项卡：压缩文件 / 解压文件。
- 压缩：拖拽选择文件、选择文件夹、清空、文件列表、压缩包名、压缩并下载、进度条。
- 解压：选择压缩包（ZIP/RAR/7z/TAR/GZ/XZ/BZ2）、提取内容、进度条、结果列表（下载单个文件）。
- 依赖 libarchive/JSZip，本地完成。

#### `/tools/tree` 树形结构可视化

- 左：上传 .json、加载示例、清空输入、复制 JSON、图配置（标签字段/布局等）；JSON 文本域；错误提示；渲染树形图。
- 右：ECharts 树图；导出图片；节点数。

#### `/tools/list-tree` 列表树可视化

- 左：上传 .txt、加载示例、清空输入、复制内容；目录树文本域；错误提示；渲染树列表；导出 JSON；在树形结构可视化中打开。
- 右：可折叠列表；导出图片、展开全部、全部折叠；节点数。

#### `/tools/code-runner` 在线代码运行

- 顶部：语言选择；未登录提示（Java/C/C++ 需登录，Python/JS/TS/Lua 本地运行）；重置示例、清空、保存到浏览器、复制代码。
- 左：CodeMirror 编辑器 + 折叠的「标准输入」。
- 右：运行输出（运行、清空、运行中状态、ANSI 彩色输出、未登录/超时/错误提示）。

#### `/tools/video-to-gif` MP4 转 GIF

- 运行核心：加载 ffmpeg 核心（首次约 24MB）、加载进度、失败重试。
- 上传：拖拽/点击选择视频；视频预览；更换视频（有结果时先确认）。
- 输出设置：帧率、分辨率、时间范围裁剪、目标尺寸等。
- 转换：转换为 GIF、进度/阶段说明、转换完成预览、下载 GIF、重新转换。

#### `/tools/markdown-to-word` Markdown 转 Word

- 选择 .md 文件、载入示例、清空、字符数。
- Markdown 文本域。
- 文件名输入、转换并下载 .docx（主按钮；无内容时禁用）。

### 4.6 `/chat` NitroBot

**会话侧栏**

| 元素 | 行为 |
| --- | --- |
| Logo + NitroBot | 回 `/` |
| 收起侧栏 / 关闭 | 桌面收起；移动端关抽屉 |
| 新建对话 | 停掉当前流式回答，清空消息 |
| 最近对话条目 | 切换会话；悬停出现删除（×） |
| 主题切换 / 返回站点 | — |
| 用户 + 退出登录 | 原生确认后登出 |

**顶栏**：展开侧栏（桌面）、打开会话列表（移动）、会话标题、右侧「通用模式」胶囊。

**消息区**

| 元素 | 行为 |
| --- | --- |
| 加载更早的消息 | 服务端会话分页（仅 `hasMore`） |
| 状态横幅 | 状态读取失败 / AI 不可用 / Agent 已关闭 / 索引未构建 |
| 空态 | 产品介绍 + 4 张随机起始提示卡（点击只填入输入框）+ 未登录「登录后开始对话」 |
| 消息操作 | 复制、继续（截断时）、重新生成（仅最后一条回答） |
| 来源 / 工具 / 技能 | 折叠展示引用、工具调用轨迹、技能列表 |
| 右侧时间轴 | 每个用户提问一个圆点，点击跳转；滚动时高亮当前 |
| 额度提示 | 90% 一次性提醒（可关闭）；用尽横幅；全站熔断横幅 |

**输入区**：联网开关（可用时）、发送 / 停止、`/` 指令菜单（quota / status / profile / clear）、底部快捷键提示、登录提示。

### 4.7 `/account` 用户中心

| 区域 | 元素 | 行为 |
| --- | --- | --- |
| 左栏 | 头像 + 昵称 + 用户名 | — |

## 6. 当前视觉/交互问题清单（供设计师判断）

1. **双设计系统**：同一页里 Tailwind `.btn` 与 `el-button` 混用（工具页 vs 管理页），
   主按钮高度、圆角、hover 不一致；图标按钮有的 28px、有的 36px。
2. **页面外壳不统一**：三种侧栏宽度、两种顶栏高度、折叠按钮图形不同；门户顶栏在
   分区页被隐藏，导致「回到门户」的入口位置每层都变。
3. **页头层级弱**：门户页 H1 24–40px，分区页 16px，后台 18px；同一产品没有统一的
   页面标题规范（字号、描述、操作区）。
4. **按钮密度与位置不稳定**：新建在页头，导出在表格行，批量在卡头，删除在行内；
   工具栏行本轮已整体移除。
5. **筛选栏控件宽度靠手写**（`w-[220px]!`），窗口变窄时换行节奏不齐；标签中英混排
   （本轮已把资源管理改成中文）。
6. **图标按钮可发现性低**：工具页大量依赖 `title` / tooltip 的纯图标按钮
   （上传、示例、清空、复制、设置），触屏用户看不到文案。
7. **表格列过多**：资源管理 10 列 + 固定操作列，1440 以下就需要横向滚动；
   插件管理把「名称+一句话简介」塞在一列。
8. **只读页缺少时间感**：索引状态、用量、审核都没有「最后更新时间」；本轮移除刷新后，
   这个问题更明显，建议加「最后检测时间 / 自动刷新」。
9. **空态/错误态文案风格不一**：有的给重试路径，有的只有「请稍后刷新」。
10. **聊天页信息密度高**：右侧时间轴、工具轨迹、来源、额度提示同时存在，窄屏容易挤；
    顶栏标题与「通用模式」胶囊的优先级可以再压。
11. **用户中心**：左栏锚点没有当前项高亮；安全操作分散在多个弹窗，缺少统一的安全状态概览。
12. **暗色是默认**：设计师需要同时给 light/dark 两套；现有 token 已支持，建议沿用而不是新造颜色。

## 8. 建议的 UI 调整方向（给设计师的 brief）

### P0 —— 统一体系（不改业务）

1. **一套按钮规范**：主 / 次 / 幽灵 / 危险 / 链接 / 图标，明确高度（28/34/36）、
   圆角（9px）、图标与文字间距、禁用与 loading；管理后台全部用同一套
   （继续用 EP 也可以，但视觉必须和 `.btn` 对齐）。
2. **一套页面头**：`面包屑（可选）+ H1 + 一句描述 + 右侧主操作`；门户/分区/后台三处
   只允许字号差异，不允许结构差异。
3. **一套侧栏**：宽度 216–240px、折叠态 64px、顶栏 56px、底部固定「主题 + 账号」；
   工具箱/插件/后台/聊天共用同一个折叠图标与动效。
4. **一套筛选栏**：标签左、控件右、按钮靠右；控件宽度按栅格（S/M/L），
   ≤991px 一项一行；区分「查询（主）」「重置（次）」。
5. **一套反馈**：加载骨架、空态插图 + 一句下一步、错误条 + 重试、成功 toast；
   明确每种状态用哪个组件。

### P1 —— 列表页与后台

6. **资源管理减列**：默认只留 `文件名 / 类型 / 大小 / 应用 / 状态 / 创建时间 / 操作`，
   其余进详情抽屉；或在 ≥1280 才显示次级列。
7. **列表页结构**：`页头（新建/导入/重载）→ 独立查询卡 → 列表卡（标题/计数 + 批量动作）→ 表格 → 分页`；
   不设单独的工具栏行，批量动作只出现在列表卡头。
8. **危险操作落点**：行内删除用红色链接 + 确认；批量在表头；与行无关的
   （恢复默认、解除熔断、重建索引）留在页底 Danger zone。
9. **只读页加时间戳**：索引状态、用量、审核显示「最后更新 hh:mm:ss」，
   需要时提供「重新检测」而不是全局刷新。

### P2 —— 门户与工具页

10. **首页/工具页卡片统一**：图标容器 38–44px、标题 15px、描述 13px、标签同款；
    减少 hover 位移与阴影的随机组合。
11. **工具页操作区**：把纯图标按钮改成「图标 + 文案」或在面板头部做显式操作条；
    上传/示例/清空/复制/设置在移动端至少可见文字。
12. **聊天页**：明确「会话列表 / 消息 / 时间轴 / 额度」四层的信息优先级；
    窄屏隐藏时间轴、额度提示压缩为一行。
13. **用户中心**：左栏加当前锚点高亮；安全区用「状态 + 主操作」两列布局，
    绑定/验证状态用统一 badge。

### 设计交付建议

- 画布：1440（桌面）、1024（小桌面/平板横）、768、390（移动）。
- 需要覆盖的组件状态：default / hover / active / focus-visible / disabled / loading / empty / error。
- 两套主题：沿用第 1.1 节 token，暗色为默认。
- 需要新画的页面：管理后台列表页（插件/资源/用量/审核/技能）、索引状态、AI 设置、
  门户首页、工具页通用壳 + 3 个代表工具（MOTD / server.properties / 代码运行）、
  插件详情、聊天页。
- 交付时请标注：按钮宽度是否随文案、表格列优先级、移动端折叠后的入口位置。
