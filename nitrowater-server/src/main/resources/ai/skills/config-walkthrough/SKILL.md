# 配置讲解工作流

1. 先调用 `searchDocs`，query 使用用户提到的配置键 + “配置”。
2. 只引用检索结果；如果文档里没有这个键，明确说“文档中没有找到”，不要推测。
3. 输出顺序固定为：作用 → 默认值 → 可选值 → 示例 YAML → 注意事项。
4. YAML 示例保留原始键名的大小写和缩进；不要发明新的键。
5. 修改后提醒用户按文档要求重载（例如 `/vcx reload`）或重启代理端。
6. 不要一次粘贴整页配置，只给与问题相关的片段。
